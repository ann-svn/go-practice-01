## Практическая работа № 2. Условия, циклы, функции и коллекции

### Выполнено 

Написана программа `task-summary`, которая выводит статусы списка задач. Всего есть 3 типа задач: новая(new), в работе(in_progress), завершена(done). Написана функция `countStatus`, принимающая список статусов и тип искомого статуса и возвращающая количество искомого статуса в заданном списке. Программа выводит количество задач, сами задачи с их статусами, количество завершённых задач и статистику - количество задач для каждого типа статуса.

Программа `task-summary` была дополнена двумя новыми функциями:
- `findStatus` - находит индекс первого совпадения или -1, если статус не найден.
- `completionPercent` - находит долю выполненных задач.

## Практическая работа № 3. Структуры, методы и указатели

### Выполнено

1. Определена `Task` с полями `ID int`, `Title string`, `Status string`, `Priority int`.
2. Реализована функция `Summary() string`, возвращающая `#2 Освоить функции [in_progress], приоритет 2` для соответствующего объекта.
3. Реализована `Complete()`, изменяющая статус исходной задачи на `done`.
4. Реализована `SetPriority(priority int) bool`: допускаются числа от 1 до 3, неверное значение ничего не изменяет.
5. Создан срез из трёх объектов с ID 1, 2, 3 и данными из каркаса.
6. Реализована `findTaskByID(tasks []Task, id int) *Task`: возвращает указатель на элемент исходного среза или nil.
7. Найдена задача с ID=2, завершена и приоритет изменён на 3.
8. Вывод всех задач через `Summary()` и число `Задач завершено: 2`.
Показано сообщение `Задача не найдена` для отсутствующего ID=99.
9. Реализована функция `tasksByStatus(tasks []Task, status string) []Task`. Возвращает новый срез задач указанного статуса.
10. Выводит задачи со статусом, который указан в переменной `status`, по умолчанию это `done`; если в `status` стоит статус, которого нет с списке задач, то выводится сообщение `Нет задач с таким статусом.`
