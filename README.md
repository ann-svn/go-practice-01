# Практическая работа № 1. Знакомство с Go

Курс «Бэкенд-разработка на языке Go».

## Окружение

- Операционная система: Fedora Linux 45 (Workstation Edition).
- Версия Go: go version go1.27.2 linux/amd64.
- Редактор: Visual Studio Code.

## Выполнено

Были выполнены все задания, обязательные и дополнительные.

Была написана первая программа - программа приветствия, был собран и запущен её исполняемый файл. 

Был проведён эксперимент того, как объявлять переменные разных типов данных и выводить их на экран. Была написана программа карточки, которая при запуске выводит участника, группу, курс, количетво завершённых работ и булевое значение интереса. 

Был сделан конвертер минут, переводящий число минут в полные часы и оставшиеся минуты. Также была сделана проверка на ввод некорректных данных (отрицательных чисел или не чисел).

Было выполнено дополнительное задание на нахождение суммы и среднего арифмитического трёх заданных целых чисел.

## Проверенные данные

### Первая программа
Входные данные: нет

Результат: программа выводит приветствие.

### Карточка
Входные данные: нет

Результат: выводит имя участника, группу, курс, количество завершённых работ и булевое значение интереса к данному курсу. В ходе выполнения программы менялось количество выполненных работ `completed`.

### Конвертер минут
Входные данные: целое неотрицательное число - количество минут.

Результат: переводит число минут в полные часы и оставшиеся минуты и выводит их на экран.

### Сумма и среднее арифмитическое
Входные данные: нет

Изначально заданы три числа: 20, 25 и 35.

Результат: программа выводит сумму трёх заданных чисел и их среднее арифмитическое с двумя знаками после точки с запятой.
