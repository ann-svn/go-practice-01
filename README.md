## Практическая работа № 2. Условия, циклы, функции и коллекции

### Выполнено 

Написана программа `task-summary`, которая выводит статусы списка задач. Всего есть 3 типа задач: новая(new), в работе(in_progress), завершена(done). Написана функция `countStatus`, принимающая список статусов и тип искомого статуса и возвращающая количество искомого статуса в заданном списке. Программа выводит количество задач, сами задачи с их статусами, количество завершённых задач и статистику - количество задач для каждого типа статуса.

Программа `task-summary` была дополнена двумя новыми функциями:
- `findStatus` - находит индекс первого совпадения или -1, если статус не найден.
- `completionPercent` - находит долю выполненных задач.
